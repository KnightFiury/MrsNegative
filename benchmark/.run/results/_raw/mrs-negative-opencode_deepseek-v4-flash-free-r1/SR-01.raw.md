## Review

🛑 [LOGIC] [CONFIRMED] The refill line doesn't accrue — it overwrites — and it deterministically defeats the limiter.

The correct refill is `tokens = min(capacity, tokens + elapsed * rate)`. The diff does `tokens = Math.max(10, Math.floor(elapsed * 10))`, and that changes the limiter's behavior entirely:

- **Evidence:** `Math.max(10, x)` is always ≥ 10, so `bucket.tokens > 0` is *always* true on every call. The `if` branch is taken unconditionally and the `else` (reject) path is dead code. `allow()` returns `true` for every request — the limiter never limits anything. Worse, `bucket.last` is only written on that unreachable reject path, so `elapsed` keeps growing from the *first* request; once it passes 1s, `floor(elapsed * 10) > 10` and the bucket starts granting over the burst cap too. The "drift" from the context is real, but the headline is simpler: any request pattern is unlimited.
- **Impact:** the rate limit (a security/abuse control) silently does nothing; nothing is ever throttled.
- **→ Fix:** accrue, cap, and advance the refill timestamp on every call:
  ```js
  const now = Date.now();
  bucket.tokens = Math.min(10, bucket.tokens + Math.floor((now - bucket.last) / 1000 * 10));
  bucket.last = now;
  if (bucket.tokens >= 1) { bucket.tokens -= 1; buckets.set(key, bucket); return true; }
  buckets.set(key, bucket); return false;
  ```
- **Verification:** fire 11 rapid `allow("k")` calls with no delay — the 11th must return `false` under burst=10; the current code returns `true` for all 11. Pin that as a regression test (failing against this diff, green against the fix).

This is a seam (shared per-key state) and the change lands exactly on it — worth saying plainly: after this fix, two concurrent writers to the same key can still race, but that's secondary; the refill bug is the whole game today.

You're not actually confident a client sending 10 requests, waiting 1 second, and sending 10 more is ever throttled, are you — you've traced that `Math.max(10, …)` keeps the bucket full on every single call?
